# BRIXEL Science Lab Bluetooth — 0.3.3 개발판 (블루투스판)

[BRIXEL Science Lab](https://github.com/brixel-editor/pxt-brixel-science-lab)의 **블루투스판**입니다. 이 확장 **하나만** 넣으면 사이언스랩의 모든 블록(센서·표시·USB 보내기)이 **자동으로 함께** 들어오고, 측정값을 **바우어버드 프로**에 블루투스(BLE, 노르딕 UART)로 보내는 블록이 더해집니다. **micro:bit V2** 전용입니다.

| 수업 | 넣을 확장 |
|---|---|
| 유선(USB) | 본 확장 `pxt-brixel-science-lab` **하나** |
| 무선(블루투스) | 블루투스 확장 `pxt-brixel-science-lab-ble` **하나**(본 확장 자동 포함) |

이 확장 0.3.3 은 본 확장 **v0.8.3** 을 품습니다. 본 확장을 따로 또 넣을 필요는 없습니다(넣더라도 같은 버전이면 괜찮지만, 다른 버전이 섞이면 MakeCode 가 충돌을 알립니다).

## 왜 따로 나눴나요?

블루투스를 넣으면 전원을 켜는 순간부터 블루투스가 계속 동작합니다. 블루투스 처리는 마이크로비트에서 가장 먼저 처리되는 일이라 DHT11 같은 시간에 민감한 센서 읽기에 끼어들어 가끔 실패를 일으키고, 메모리도 더 씁니다. 그래서 유선만 쓰는 수업에서는 블루투스를 아예 켜지 않도록 짝 확장으로 분리했습니다.

## MakeCode에 추가하기

**확장** 검색창에 다음 주소를 붙여 넣습니다. 본 확장은 자동으로 함께 들어옵니다.

```text
https://github.com/brixel-editor/pxt-brixel-science-lab-ble
```

`radio`와 함께 쓸 수 없다는 안내가 나오면 **radio를 제거**합니다. 블루투스와 radio(마이크로비트끼리 무선 통신)는 동시에 쓸 수 없습니다.

## 블록 (카테고리: 바우어버드 블루투스)

| 블록 | 쓰는 곳 |
|---|---|
| `블루투스 연결 시작` | 「시작하면」에서 한 번 |
| `블루투스 연결됨` | 연결 여부(참/거짓) |
| `측정값 (값) 바우어버드로 블루투스 보내기` | 센서 값 하나 보내기 |
| `측정값 (배열) 바우어버드로 블루투스 보내기` | 여러 센서 값을 한 줄로 보내기 |

연결되기 전에는 아무것도 보내지 않습니다. 보내는 형식은 USB 블록과 같습니다(쉼표로 나눈 숫자만, 한 줄 = 측정 1회, 머리글·단위 없음).

## 예제

```blocks
scienceBluetooth.startBluetooth()
basic.forever(function () {
    scienceBluetooth.sendValueBluetooth(input.temperature())
    basic.pause(1000)
})
```

## 주의

- 블루투스가 켜진 동안에는 기본 **음악 블록**(소리 재생)과 함께 쓰면 마이크로비트가 오류(070)로 멈출 수 있습니다.
- 이전에 본 확장(v0.6.x)의 블루투스 블록으로 만든 작품은 이 블루투스 확장을 추가하면 같은 블록이 다시 연결됩니다(blockId·JavaScript 이름 `scienceBluetooth.*` 그대로).
- 0.2.0 부터 보내는 줄의 형식(숫자만·쉼표·NaN/Infinity 줄 버림)은 본 확장의 `scienceData.encode` 를 그대로 씁니다(전에는 같은 규칙의 사본).
